# Python Turtle

This repository contains a few beginner-friendly Python exercises that use the built-in `turtle` graphics library to draw simple shapes, patterns, and faces.

It is a small learning project meant to help practice:

- Python syntax and control flow
- Using the `turtle` module
- Drawing basic geometric shapes
- Creating simple visual designs with loops and movement commands

## Project files

- `turtle-ex1.py` — draws a geometric design using circles, lines, and arcs.
- `turtle-ex2.py` — creates a repeated wave-like pattern and circular forms.
- `turtle_smiles.py` — draws a smiling face using a circle, eyes, and a curved smile.

## Requirements

- Python 3.x
- A desktop environment that supports Tkinter-based graphics

## How to run

From the repository folder, run any script with Python:

```bash
python turtle-ex1.py
```

```bash
python turtle-ex2.py
```

```bash
python turtle_smiles.py
```
## Notes

These scripts are ideal for beginners learning Python graphics and can be modified to experiment with different colors, shapes, positions, and motion.
